System Guide

How to use MindCare. Print this and share it with a new counselor on their first day.

1. Logging in

Everyone uses the same login page; the system opens the right dashboard for your role.

  1. Go to the MindCare home page and click Login.
  2. Enter your email and password (given to you by the admin).
  3. You land on your own dashboard automatically.
  4. Always click Logout (top right) when you finish — student data is private.

2. Who does what (roles)

MindCare has five roles. Each one only sees what it needs.

  • Student Books sessions, writes a private diary, uses the relaxation zone, reads resources.
  • Counselor Manages appointments, reviews shared diaries, responds to risk alerts, adds resources & relaxation content.
  • Learning Advisor Handles academic-relief requests forwarded to them.
  • Guardian Books an emergency session for a student (via OTP), without seeing the diary.
  • Admin Manages users, moderates the forum, updates emergency numbers, runs backups.

3. Admin — adding a new counselor

This is how you onboard a new counselor account.

  1. Go to User Management.
  2. Click + Add User.
  3. Fill in the name and email, and choose the role Counselor.
  4. Set a starting password and click Save.
  5. Share the login details with them, and give them this guide.
  6. To pause an account later, use Deactivate; to fix a lost password, use Reset Password.

4. Counselor — daily work

The main things a counselor does in MindCare.

  1. Appointments: see pending booking requests and accept or update them. If a student cancels, it appears under Cancellation Notices with their reason.
  2. Student Alerts : the system automatically scans diary entries for distress keywords (even private ones). Flagged students appear here. Use Contact Student to reach out, then Mark Reviewed.
  3. Shared Diaries: read diary entries a student chose to share with you.
  4. Student Wellbeing / Reports: view a student's PHQ-9 wellbeing snapshot; print or download the report.
  5. Resource Manager: add, edit or remove articles and resources students can read.
  6. Relaxation Zone: add or edit breathing exercises, meditations and calming content.
  7. My Notes: your own private notepad and per-student session notes (kept as a full history).

5. Reserved emergency slots & guardians

How urgent bookings work.

  • Two slots are kept reserved for emergencies — one per counselor (e.g. 9:30 AM and 2:00 PM).
  • A guardian verifies by OTP and can book one of these reserved slots for a student.
  • If both reserved slots are already taken, the guardian can send the counselor an urgent email instead.

6. Admin — safety & backups

Keep the system and its data safe.

  1. Under Security & Backups, moderate any reported forum posts (Delete or Dismiss).
  2. Keep the emergency contact numbers up to date.
  3. Click ▶ Run Database Backup Now regularly to save a full copy of the database.
  4. Important: download the backup and keep one copy off the server (Google Drive, email, or a USB drive). If the computer fails, the data still survives.

7. If a student is in crisis

Real help, outside the app.

  • 1926 — National Mental Health Helpline
  • 011-2692909 — Sumithrayo
  • 011-4602806 — Childline / CCCline
  • The keyword scanner is only an early warning — a real person must always follow up.
